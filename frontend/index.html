What the agent does

Practical features for small businesses, built to be honest about what it knows.

Answers from your data

Prices, variations, availability, delivery, opening hours, payment instructions and FAQs you set in the Knowledge Base.

Order collection

Multi-step requests with a summary for the customer to confirm. Owners review and update the status. Payment is tracked separately and never assumed.

Human handoff

If the agent has no answer it does not invent one. It records a handoff with a copyable summary for you to resolve.

Follow-up reminders

Customers who showed interest but did not order get suggested messages you can edit, copy, mark sent, or stop.

Multi-business

Each business has its own products, customers, conversations and credentials, kept strictly separate.

Real numbers

Analytics come from your actual records. With no activity you see an empty state, not made-up figures.

WhatsApp, the official way

Uses Meta's WhatsApp Business Cloud API with signature-checked webhooks. Credentials stay on the server. No WhatsApp Web automation, no personal accounts.

Connecting needs a Meta developer app, a WhatsApp Business phone number, a permanent access token and a public HTTPS webhook URL. Until you complete that setup, use the built-in local simulator, which is clearly labelled and never contacts WhatsApp.

FAQ

Is this a large language model?

No. The initial agent uses local rules: intent matching, saved conversation state and your configured information. It is structured so a model could be added later.

Does it need any paid API keys?

No. The agent and dashboard run fully on your machine with no AI API key. WhatsApp itself requires Meta credentials if you want real WhatsApp messaging.

Does it take payments?

No. There is no checkout or payment integration. Order status and payment status are separate, and you decide when a payment is verified.

What if the agent doesn't know the answer?

It says so, records a handoff for you, and never makes up information.

Can I message customers automatically?

Only in line with WhatsApp rules. Replies to customer messages are supported; follow-ups outside the 24-hour window require approved templates, which this app does not send.
